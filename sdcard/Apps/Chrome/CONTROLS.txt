Chrome on TRIMUI Brick Pro — ボタン操作（日本語版）
================================================
本体は任天堂配置（A が右、B が下、X が上、Y が左）。下の表は本体の印字どおり。

【ページを見ているとき】
左スティック      ポインタを動かす
A（右）           クリック / 決定
Y（左）           右クリック
B（下）           Esc（取り消し / ポップアップを閉じる）
X（上）           1文字消す（BackSpace）
START             Enter
SELECT            Tab
L1 / R1           ページアップ / ページダウン
十字キー 上下     スクロール
十字キー 左右     戻る / 進む
右スティック 上下 スクロール
L2 / R2           縮小 / 拡大
右スティック押し込み  アドレスバーへ
左スティック押し込み  再読み込み
MENU 短押し       画面キーボードを開く / 閉じる
MENU 長押し       音声入力（話して離すと入力される。https のページのみ）
SELECT+START      Chrome を終了して元の画面に戻る

【画面キーボードを開いているとき】十字キーはキーボードの操作になる
十字キー          キーを選ぶ
A                 選んだキーを押す
B                 キーボードを閉じる（日本語の入力中は取り消し）
Shift             大文字 / 記号（1回押すと固定、もう1回で解除）
ABC / あ          英字 ⇔ 日本語（ローマ字かな漢字変換）

キーの並び:
  数字
  qwerty
  asdf... + 削除
  Shift + zxcv...
  ABC/あ - , スペース .com 音声 音波 改行 閉じる

【日本語入力】左下の「ABC」を押すと「あ」（紫）になる
ローマ字で打つ    画面上部にひらがなで表示（nn → ん、kitte → きって）
スペース          漢字に変換。続けて押すと次の候補（漢字 → カタカナ → ひらがな）
改行 / START      確定
削除 / X          1文字消す（変換中は変換前に戻る）
B                 取り消し
- . , /           ー 。 、 ・
変換は Google の変換サービス（www.google.com/transliterate）を使う。ネット接続が必要で、
変換する文字は Google に送られる。文節の区切りは直せないので、単語ごとに変換するとよい。

【音波入力】PC のスピーカーから文字を「音」で送る
キーボードの「音波」を選んで A → 15 秒録音する。PC で:
    ./tools/audio-send.py "入力したい文字"
もう一度「音波」か B で取り消し。最大 255 バイト。

【設定】
最初に開くページ: /mnt/SDCARD/Apps/Chrome/homepage.txt（1行目）
表示倍率: scale.txt（1 = 100%、1.5 = 150%）
ポインタの速さ: pointer.txt
GPU 加速: gpu.txt（1 = オン、0 = オフ）
ログ: /opt/brick-chrome/tmp/brick-app.log、brick-pad.log
